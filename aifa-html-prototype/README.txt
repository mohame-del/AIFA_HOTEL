# AIFA Hotel Management System - Standalone HTML Prototype

## How to Open

1. Extract/unzip ifa-html-prototype.zip to a local folder
2. Open index.html directly in any modern web browser (Chrome, Firefox, Edge, Safari)
3. No server, build tools, or Node.js required - runs entirely offline with local assets

## Notes
- This is a faithful structural replica of the original Next.js application
- All text, labels, colors, and layout follow the original design
- Interactions are simplified for prototype demonstration
- Design tokens preserved from original (dark theme with champagne/gold accents)
